2026 · MCA project01

Wi-Fi Sense

AI-powered indoor monitoring using Wi-Fi Channel State Information — no cameras, no wearables.

A multi-tenant platform where one codebase serves elder-care homes (caregivers, doctors, families tracking resident safety and alerts) and corporate buildings (live room occupancy and booking).

Two ESP32-S3 boards running custom ESP-IDF firmware form the sensing link; a Python serial bridge streams CSI to an authenticated ingest API. A React 19 frontend talks to a FastAPI backend with JWT auth and rotating refresh tokens. Every value on screen is labelled with its source — demo, dataset replay, or live hardware.

Honest resultThe random-forest fall model reaches ~0.69 balanced accuracy on unseen people and confuses sitting with falling — so the system only raises a possible fall for a caregiver to verify, and live boards report presence and motion instead.

2026 · Containerised app02

SkillTree

Track what you're learning as a game-style radial skill tree.

Each skill is a node on a dot-matrix map with a branch, level, progress and status. Fully containerised: three services on a private bridge network, with only the UI port exposed to the host. The API runs as a non-root user with a healthcheck; MongoDB persists to a named volume. Ships with Kubernetes manifests too.
